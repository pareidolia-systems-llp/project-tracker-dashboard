# Enterprise Project Tracker Dashboard
## Architecture & Development Specification (ADS)
### Version 1.0

This document defines the technical architecture and development standards.

## Project Vision
- Google Sheets is the operational tracker.
- Spring Boot synchronizes data into MySQL.
- MySQL is the reporting database.
- Apache Superset powers dashboards.
- React will replace Google Sheets in a future version.

## Guiding Principles
- Preserve business terminology.
- Database models the business domain.
- DTO → Validation → Mapper → Entity → Repository.
- Business logic belongs in Services.
- Follow layered architecture and SOLID.

## High-Level Architecture
Google Sheets → Google Sheets API → Scheduler → GoogleSheetsService → GoogleSheetRowDTO → Validation → Normalization → Mapper → Business Entities → MySQL → REST APIs → Apache Superset / React

## Package Responsibilities
config, constants, controller, dto, entity, enums, exception, google, mapper, repository, scheduler, service, service.impl, util, validation.

## Database Philosophy
Google Sheet → DTO → Validation → Normalization → Business Model → Database

## Synchronization Strategy
Scheduler → API → DTO → Validation → Mapper → Entity → Change Detection → Current Data → Snapshot → Sync History

2. Week Of

This is not just a date.

It is a Business Week Identifier.

Business Reporting Period

The dashboard follows a business-defined reporting period rather than ISO weeks or Monday–Sunday weeks.

Each calendar month is divided into four reporting periods:

Week 1 : 01 – 07

Week 2 : 08 – 14

Week 3 : 15 – 21

Week 4 : 22 – Last Day of Month

Examples:

June 2026
01–07

08–14

15–21

22–30

July 2026
01–07

08–14

15–21

22–31

The final reporting period always extends to the last day of the current month, even if it contains more than seven days.

Reporting periods must never span across two calendar months.

This business rule has been defined to simplify monthly operational reporting and management review meetings.
Reporting Implications

The Week Of column represents a business reporting period, not an ISO week.
